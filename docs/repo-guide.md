# 레포 가이드

## 이 레포의 역할

이 레포는 A&I 백엔드 커리큘럼의 `11. 리팩토링과 기초 보강` 시퀀스를 담당합니다.

핵심 메시지는 아래입니다.

- 새로운 기술을 하나 더 붙이기보다, 지금까지 만든 코드를 다시 읽는다
- 역할이 섞인 부분을 더 읽기 쉬운 구조로 정리한다
- Validation, Exception Handling, 테스트, 문서화를 하나의 흐름으로 다시 묶는다
- “작동하는 코드”를 “설명 가능한 코드”로 다듬는 감각을 익힌다

## 이 레포에서 직접 다루는 범위

- Service 리팩토링 포인트 1개
- Validation 또는 Exception Handling 보강 1개
- 테스트 보강 1~2개
- README 또는 문서 보강

## 이 레포에서 깊게 다루지 않는 범위

- 새로운 대형 기술 주제
- Kafka, CQRS, DDD, 멀티모듈
- 성능 최적화 전체
- 전면 재작성 수준의 대규모 리팩토링
