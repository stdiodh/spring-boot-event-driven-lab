# 이벤트 기반 사고 확장 체크리스트

## 학생 체크리스트

- [ ] 동기 호출과 비동기 전달 차이를 설명할 수 있습니다.
- [ ] 이벤트가 무엇인지 이번 예시 기준으로 설명할 수 있습니다.
- [ ] 발행자와 소비자의 역할 차이를 말할 수 있습니다.
- [ ] 메시지 큐가 왜 필요한지 입문 수준에서 설명할 수 있습니다.
- [ ] 주문 생성 후 알림이 분리된 흐름으로 이어지는 것을 확인했습니다.

## 강사 / PPT 체크리스트

- [ ] 주문 생성 → 이벤트 발행 → 알림 소비 그림이 있는가
- [ ] 직접 호출과 이벤트 전달 차이를 예시로 설명할 수 있는가
- [ ] 메시지 큐를 너무 무겁지 않게 소개하고 있는가
- [ ] MSA가 무조건 답이 아니라는 점을 함께 설명할 수 있는가
