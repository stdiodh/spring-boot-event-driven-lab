# Deprecated Answer Guide

이 문서는 예전 링크 호환을 위해 남겨둔 안내 문서입니다.
`main` 가이드 브랜치에서는 완성 구현 자료를 직접 제공하지 않습니다.

멘티는 `12-implementation`에서 실습을 진행한 뒤, 막혔거나 완료 확인이 필요할 때만 별도 비교 브랜치를 확인합니다.
멘토용 비교 포인트와 완성 구현 자료는 별도 비교 브랜치의 기본 문서 안에서 관리합니다.
